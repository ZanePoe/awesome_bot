# i18n layout

Every catalogue ships the same reading surface in five languages: English (default, repo root), Simplified Chinese, Spanish, Hindi and French (top five languages by total speakers).

## Output tree

| Path | Content |
| --- | --- |
| `README.md`, `docs/projects.md`, `docs/papers.md`, `docs/rankings.md`, `docs/<static>.md`, `CONTRIBUTING.md` | English (default) |
| `locales/<lang>/README.md`, `locales/<lang>/docs/projects.md`, `locales/<lang>/docs/papers.md`, `locales/<lang>/docs/rankings.md`, `locales/<lang>/docs/<static>.md`, `locales/<lang>/CONTRIBUTING.md` | one mirror per locale in `zh`, `es`, `hi`, `fr` |

Static prose in this catalogue: `docs/readme-intro.md`, `docs/taxonomy.md`, `docs/methodology.md`, `docs/research.md`, `docs/harness-guide.md`, `CONTRIBUTING.md`.

`locales/<lang>` mirrors the root layout, so relative links inside a mirror (`docs/projects.md`, `rankings.md`, `CONTRIBUTING.md`) are written once in the templates. Shared originals that stay at the root (`LICENSE`, `data/`, `scripts/`, `record/`) are addressed through the `{R}` prefix, computed by `prefix(locale, depth)` with `depth=0` for a file at the locale root (the README) and `depth=1` for a generated file inside the locale's `docs/`: English `""` / `"../"`, a mirror `"../../"` / `"../../../"`.

Relative-link depth for hand-written prose (not templates): links from `docs/*.md` to the repository root resolve from that file's own directory — one `../` level at the English root, one level deeper per mirror directory hop, e.g. `../research/search-log.json` in root `docs/research.md` becomes `../../../research/search-log.json` in `locales/<lang>/docs/research.md`. `docs/readme-intro.md` is the exception: it is inlined into the README (`build.INLINE`), so its links resolve from the locale root.

Language switcher: the generated README of every locale starts with the same line linking all five.

## Source of truth

| File | Role |
| --- | --- |
| `data/projects.json` | canonical review data, written in Chinese; also the fallback for `zh` |
| `data/papers.json` | canonical paper review data, written in Chinese; also the fallback for `zh` |
| `locales/<lang>/ui.json` | `language`, `language_name`, `list_separator` plus category, paper-category, scope, licence-status, tier, mode labels, table headers, section titles and paragraph templates |
| `locales/<lang>/entries.json` | `repo → {description, boundary, trigger, license_label, license_note}` for that language (`evidence_notes` in the extraction source is not rendered and is dropped; `name` may only be added when the canonical name contains Chinese characters) |
| `locales/<lang>/papers.json` | `arXiv id → {title, summary, boundary, publication_note}` for that language |
| `locales/<lang>/docs/*.md`, `locales/<lang>/CONTRIBUTING.md` | hand-written static prose per locale |
| `locales/zh/ui.json` | the Chinese strings `build.py` used to hard-code; it is the translation source for every other locale |

`zh` has no `entries.json` or `papers.json` — `build.py` falls back to `data/projects.json` and `data/papers.json`. Every other locale must provide one entry per repository and per paper, or `validate()` fails.

## What stays fixed across languages

Project detail anchors in `docs/projects.md` are `<a id="owner--repo">` tags derived from the canonical repository name via `anchor(repo)`; they do not change with the language, so cross-language deep links to a project stay stable. Paper entries are identified by arXiv URL.

## Translation rules

- Keep facts identical to the Chinese source. Do not add claims, benchmarks or guarantees.
- Leave unchanged: repository names, project names, URLs, file paths, commit SHAs, arXiv IDs, license identifiers (MIT, Apache-2.0, CC-BY-NC-4.0 …), star counts, dates, model names, code blocks, Markdown table shape, and the `<a id>` anchors.
- Literal search keywords inside `docs/research.md` stay verbatim; only the surrounding prose and table headers are translated. That file is the one exception to the no-Chinese rule for non-`zh` locales, and `tests/test_i18n.py` enforces the narrow form of the exception: Chinese may appear only in Markdown table rows or inside backticks, never in prose lines.
- `record/` is an audit trail in the language it was written in; each locale links to it and says so (`records_note`). The same holds for `research/` payloads.
