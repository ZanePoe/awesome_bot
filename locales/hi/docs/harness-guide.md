# मौजूदा Agent को प्रैएक्टिव असिस्टेंट बनाना

पहले निष्पादन-आधार चुनें, फिर ट्रिगर, निरंतर स्थिति और परिणाम-डिलीवरी जोड़ें। केवल एक cron जोड़ने से शेड्यूल शुरुआत हल हो सकती है, पर आवश्यकता-समझ और दीर्घकालिक लक्ष्य-प्रबंधन अपने आप नहीं मिलता।

| मौजूदा आधार | जाँचने योग्य रास्ता | सत्यापित तंत्र | वर्तमान सीमा |
| --- | --- | --- | --- |
| Pi | [rho](https://github.com/mikeyobrien/rho) | सदैव संचालन, स्थायी स्मृति, heartbeat | Pi का ऊपरी-स्तरीय ऐप; संचालन-प्लेटफ़ॉर्म और मेंटेनेंस स्नैपशॉट जाँचें |
| Pi / Claude / Codex CLI | [murmur](https://github.com/t0dorakis/murmur) | Markdown टास्क-परिभाषा से आवधिक CLI जागरण | डिलीवरी और व्यावसायिक कार्य बुलाए गए Agent के हिस्से रहते हैं |
| DeepSeek Harness | [dsh-proactive](https://github.com/john-walks-slow/dsh-proactive) | होस्ट-स्तरीय शेड्यूल से ठंडे सेशन जागरण, मौन समापन | DSH / प्लगइन संस्करण मिलाएँ; होस्ट का चलना आवश्यक है |
| DeepSeek Harness | [DS Bot](https://github.com/Fei2411/DS-Bot) | निरंतर नामेड Bot, ग्रुप चैट और स्मृति | होमपेज पर स्वतंत्र शेड्यूल तंत्र सिद्ध नहीं; अन्य प्लगइनों के संयोजन का रन-टेस्ट बाकी |
| Hermes Agent | [अंतर्निहित cron](https://hermes-agent.nousresearch.com/docs/user-guide/features/cron) | बिना-मानव-हस्तक्षेप शेड्यूल कार्य और चैनल डिलीवरी | पहले अंतर्निहित तंत्र इस्तेमाल करें; इस निर्देशिका ने उपयोगकर्ता की ओर से तैनात नहीं किया |
| Hermes डेस्कटॉप | [Hermes Bot Mode](https://github.com/NousResearch/Hermes-Bot-Mode) | Bot UI + होस्ट cron routines | वर्तमान में संग्रहित; केवल डिज़ाइन और कोड-संदर्भ रखा गया |
| OpenClaw | [Pulse](https://github.com/Hypostas/pulse) | सेंसिंग और आपातता-संचालित webhook जागरण | होस्ट पर निर्भर; सभी cron क्षमता का विकल्प नहीं |
| Letta | [Letta Code](https://github.com/letta-ai/letta-code) + [scheduling](https://docs.letta.com/letta-code/scheduling) | स्थायी Agent, remote environments, self-managed schedules | LettaBot का समर्थन बंद हो चुका है; माइग्रेशन में आधिकारिक नया रास्ता प्राथमिक संदर्भ |
| MCP-समर्थित कोई भी होस्ट | [Windows-MCP](https://github.com/CursorTouch/Windows-MCP) | Windows संचालन टूल | केवल निष्पादन-परत पूरी करता है; ट्रिगर, स्थिति और डिलीवरी अलग चाहिए |

ऊपर सार्वजनिक डॉक्यूमेंटेशन से पुष्टि किए गए संयोजन-प्रवेश हैं, संगतता-इंटीग्रेशन टेस्ट की रिपोर्ट नहीं। पहली जाँच के लिए "निश्चित समय पर अलग डायरेक्टरी में एक फ़ाइल बनाना" न्यूनतम कार्य रखें, फिर देखें कि बिना-परिवर्तन पर मौन रहता है या नहीं और रीस्टार्ट के बाद कार्य दोहराता है या नहीं।

सभी परियोजनाओं के प्रमाण, लाइसेंस और सत्यापन-तिथियाँ [प्रोजेक्ट विवरण तालिका](projects.md) में हैं।
