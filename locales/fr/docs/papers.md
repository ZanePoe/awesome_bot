# Catalogue des publications

Titres et dates de première soumission vérifiés sur les pages de résumé arXiv d'origine (2026-11-05). Les versions et renommages d'un même identifiant arXiv comptent pour un seul article. Un statut de conférence sans vérification séparée reste indiqué comme arXiv.


## [Foundations of Proactive Agents: Principles, Technical Layers, and Proactivity-Gym](https://arxiv.org/abs/2609.37267)

- Catégorie : Définitions, mécanismes et recherche fondamentale ; première soumission : 2026-09-29 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Discute les couches techniques et le coût pour l'utilisateur des agents proactifs, et introduit Proactivity-Gym.
- Limites de lecture : Cadre conceptuel et environnement d'évaluation, pas un palmarès de qualité produit.
- Ressource : Lien de code non vérifié lors de cette passe.

## [ContextAgent: Context-Aware Proactive LLM Agents with Open-World Sensory Perceptions](https://arxiv.org/abs/2505.14668)

- Catégorie : Définitions, mécanismes et recherche fondamentale ; première soumission : 2025-05-20 ; NeurIPS 2025 (indiqué sur la page de l'article).
- Question étudiée : Exploite le contexte perceptif d'appareils portables et le profil historique pour prédire quand proposer un service et appeler des outils.
- Limites de lecture : L'évaluation de la perception et de la prédiction de service n'équivaut pas à un contrôle autonome de tout le bureau.
- Ressource : [Code](https://github.com/openaiotlab/ContextAgent).

## [Proactive Agent: Shifting LLM Agents from Reactive Responses to Active Assistance](https://arxiv.org/abs/2410.12361)

- Catégorie : Définitions, mécanismes et recherche fondamentale ; première soumission : 2024-10-16 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Anticipe les tâches de l'utilisateur à partir des événements du bureau et étudie l'assistance proactive sans consigne explicite.
- Limites de lecture : Implémentation de recherche et benchmark, pas un produit d'assistant always-on abouti.
- Ressource : [Code](https://github.com/thunlp/ProactiveAgent).

## [Generative Agents: Interactive Simulacra of Human Behavior](https://arxiv.org/abs/2304.03442)

- Catégorie : Définitions, mécanismes et recherche fondamentale ; première soumission : 2023-04-07 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Étudie la construction d'agents simulés capables de vivre et d'interagir de façon autonome grâce à la mémoire, la réflexion et la planification.
- Limites de lecture : Recherche fondamentale sur les mondes simulés, pas un assistant informatique personnel.
- Ressource : Lien de code non vérifié lors de cette passe.

## [nanoMuse: An Open-Source Personal Agent for Every Device You Own](https://arxiv.org/abs/2610.08699)

- Catégorie : Systèmes d'agents personnels ; première soumission : 2026-10-06 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Présente l'architecture logicielle, la mémoire et la conception d'interaction continue de l'agent personnel multi-appareils.
- Limites de lecture : Article de système ; les affirmations d'antériorité des auteurs ne sont pas prises pour des faits vérifiés.
- Ressource : [Code](https://github.com/nano-muse/nanoMuse).

## [MemoProAgent: Toward Memory-Driven Proactive Assistance](https://arxiv.org/abs/2610.22671)

- Catégorie : Mémoire de long terme et besoins latents ; première soumission : 2026-10-15 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Étudie la récupération, dans la mémoire personnelle de long terme, des éléments justifiant une intervention, la mémoire participant à la décision de parler ou non.
- Limites de lecture : Titre de la version la plus récente : MemoProAgent ; l'ancien nom ProPerAgent n'est pas listé deux fois.
- Ressource : [Code](https://github.com/facebookresearch/Memo-Pro-Agent).

## [PASK: Toward Intent-Aware Proactive Agents with Long-Term Memory](https://arxiv.org/abs/2604.08000)

- Catégorie : Mémoire de long terme et besoins latents ; première soumission : 2026-04-09 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Combine mémoire de long terme, contexte temps réel et contraintes de latence pour détecter les besoins latents et choisir entre aider ou se taire.
- Limites de lecture : Les auteurs le présentent comme un rapport technique et une recherche en cours.
- Ressource : [Code](https://github.com/xzf-thu/Pask).

## [π-Bench: Evaluating Proactive Personal Assistant Agents in Long-Horizon Workflows](https://arxiv.org/abs/2605.14678)

- Catégorie : Benchmarks de la proactivité ; première soumission : 2026-05-14 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Évalue l'identification de besoins cachés et l'assistance proactive dans des flux de travail multi-tours de long terme.
- Limites de lecture : Le taux de réussite des tâches et la proactivité sont des métriques distinctes.
- Ressource : [Code](https://github.com/Simplified-Reasoning/Pi-Bench).

## [KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation](https://arxiv.org/abs/2604.08455)

- Catégorie : Benchmarks de la proactivité ; première soumission : 2026-04-09 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Évalue la façon dont un agent mobile recueille les préférences par l'interaction, intervient de sa propre initiative, demande l'accord ou reste silencieux.
- Limites de lecture : Scénarios d'interface mobile et de préférences personnelles ; les flux de travail de bureau restent à tester séparément.
- Ressource : [Code](https://github.com/ZJU-REAL/KnowU-Bench).

## [Proactive Agent Research Environment: Simulating Active Users to Evaluate Proactive Assistants](https://arxiv.org/abs/2604.00842)

- Catégorie : Benchmarks de la proactivité ; première soumission : 2026-04-01 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Étudie les assistants proactifs dans un environnement simulé d'applications à état et d'utilisateurs actifs.
- Limites de lecture : Les résultats obtenus sur des utilisateurs simulés ne remplacent pas directement une évaluation auprès de vrais utilisateurs sur la durée.
- Ressource : [Code](https://github.com/deepakn97/pare).

## [ProactiveBench: Benchmarking Proactiveness in Multimodal Large Language Models](https://arxiv.org/abs/2603.19466)

- Catégorie : Benchmarks de la proactivité ; première soumission : 2026-03-19 ; ECCV 2026 (indiqué sur la page de l'article).
- Question étudiée : Évalue la capacité des modèles multimodaux à obtenir spontanément des informations supplémentaires pour mener à bien une tâche visuelle.
- Limites de lecture : Distinct du benchmark homonyme de ProactiveAgent ; la page de l'article indique actuellement ECCV 2026.
- Ressource : [Code](https://github.com/tdemin16/proactivebench).

## [PIRA-Bench: A Transition from Reactive GUI Agents to GUI-based Proactive Intent Recommendation Agents](https://arxiv.org/abs/2603.08013)

- Catégorie : Benchmarks de la proactivité ; première soumission : 2026-03-09 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Recommande des intentions latentes à partir de captures successives de l'interface et du contexte de l'utilisateur.
- Limites de lecture : Recommander une intention et achever réellement la tâche recommandée doivent être évalués séparément.
- Ressource : Lien de code non vérifié lors de cette passe.

## [ProAgentBench: Evaluating LLM Agents for Proactive Assistance with Real-World Data](https://arxiv.org/abs/2602.04482)

- Catégorie : Benchmarks de la proactivité ; première soumission : 2026-02-04 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Évalue le moment et le contenu de l'assistance proactive à partir de journaux de flux de travail réels.
- Limites de lecture : Porte sur la décision d'assister, pas sur la fiabilité du système dans son ensemble.
- Ressource : Lien de code non vérifié lors de cette passe.

## [MyPCBench: A Benchmark for Personally Intelligent Computer-Use Agents](https://arxiv.org/abs/2606.16748)

- Catégorie : Contrôle de l'ordinateur et exécution personnalisée ; première soumission : 2026-06-15 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Évalue des assistants capables d'agir sur l'ordinateur dans un environnement numérique doté de données personnelles et de sessions connectées.
- Limites de lecture : Évaluation de l'exécution personnalisée ; elle ne remplace pas celle du moment des interventions proactives.
- Ressource : Lien de code non vérifié lors de cette passe.

## [OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments](https://arxiv.org/abs/2404.07972)

- Catégorie : Contrôle de l'ordinateur et exécution personnalisée ; première soumission : 2024-04-11 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Fournit un benchmark d'exécution de tâches ouvertes dans de véritables environnements informatiques.
- Limites de lecture : Mesure surtout l'exécution ; ne prouve pas qu'un agent découvre des tâches de sa propre initiative.
- Ressource : [Code](https://github.com/xlang-ai/OSWorld).

## [Sleeper Channels and Provenance Gates: Persistent Prompt Injection in Always-on Autonomous AI Agents](https://arxiv.org/abs/2605.13471)

- Catégorie : Fonctionnement de longue durée et fiabilité ; première soumission : 2026-05-13 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Analyse les chemins d'injection indirecte de prompts persistant à travers mémoire, compétences, ordonnancement et système de fichiers.
- Limites de lecture : Recherche sur l'architecture et les menaces, pas une notation de sécurité générale applicable aux produits actuels.
- Ressource : Lien de code non vérifié lors de cette passe.

## [Mind Your HEARTBEAT! Claw Background Execution Inherently Enables Silent Memory Pollution](https://arxiv.org/abs/2603.23064)

- Catégorie : Fonctionnement de longue durée et fiabilité ; première soumission : 2026-03-24 ; arXiv ; statut de conférence non vérifié séparément.
- Question étudiée : Étudie la pollution silencieuse de la mémoire provoquée par un heartbeat d'arrière-plan exposé à du contenu non fiable.
- Limites de lecture : L'évaluation est bornée par des versions ; les conclusions antérieures au correctif ne s'appliquent pas à toutes les versions actuelles.
- Ressource : Lien de code non vérifié lors de cette passe.
