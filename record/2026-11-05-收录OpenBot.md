# 2026-11-05 收录 OpenBot

- 项目：<https://github.com/CopilotKit/OpenBot>
- 分类：工作空间与上下文助手
- 范围：核心主动项目
- 触发：定时 routines / 人工发起
- 许可：MIT；CopilotKit Intelligence 的部署和许可证条件另计

OpenBot 为任意 AG-UI Agent 提供独立电脑环境，包括浏览器、文件工作区和受策略约束的工具调用。所有动作通过网关决定并记录；routines 可按计划运行，并具有最小间隔、数量上限和连续失败自动停用等边界。

本目录不把 OpenBot 本身描述为模型或 Agent 智能来源。实际推理能力来自接入的 AG-UI endpoint；持久会话与记忆依赖 CopilotKit Intelligence。功能判断来自固定提交 `5b94b6aa881fb7829abd4c931489415c28815122` 的 README，未进行实机能力测试。
