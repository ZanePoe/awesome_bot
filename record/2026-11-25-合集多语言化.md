# 2026-11-25 合集多语言化

按 `awesome_ai_video_creation` 已合入的框架移植：英语为默认（仓库根），中文/西班牙语/印地语/法语镜像在 `locales/<lang>/`。生成物从 4 件增加到 21 件（4 面 × 5 语言 + `data/rankings.csv`）。

## 本仓库的特有设计

- `locales/<lang>/ui.json` 顶层 13 键（多 `paper_categories`），`templates` 17 键（含 `projects_note`、`papers_note`、`papers_link`、`papers_intro`、`paper_entry`、`paper_code_link`、`paper_code_none`）；本仓库 README 没有「如何选择」一节，所以没有 `choose` 键。
- 条目文案在 `locales/<lang>/entries.json`（`description`、`trigger`、`boundary`、`license_label`、`license_note`），论文文案在 `locales/<lang>/papers.json`（17 个 arXiv id × `title`、`summary`、`boundary`、`publication_note`）；`zh` 回落 `data/projects.json` 与 `data/papers.json`。
- 44 个规范名均不含 CJK，因此本仓库不需要 `name` 覆盖；`test_canonical_display_names_need_no_localization` 会在将来出现中文名时失败，提醒补覆盖。
- 生成面多出 `docs/papers.md`；`<a id="owner--repo">` 由 `anchor(repo)` 生成，语言无关，译文保持不动。

## 移植时修掉的框架缺陷

1. `check_links()` 的生成物豁免改为比较解析后的绝对路径与该语言的生成物集合，译文里的平级链接（`projects.md`、`rankings.md`）不再被误判断链，也解决了「先 validate 后渲染」的首轮死锁。
2. `render_all` 混用 `str(Path)` 与 `.as_posix()` 键名，Windows 上读回镜像 README 必 `KeyError`；统一 `as_posix()`。
3. `validate()` 与测试各写一套「无汉字」正则（只用 Han 区间，漏 `、`、`「」` 等全角标点）；统一为 `build.CJK`。
4. README 的标题锚点改用新的 `heading_anchor(title)`，并按 GitHub 渲染页实测校准：小写、空格转连字符、保留字母/数字/Unicode 组合符（Mn/Mc/Me）/`_`/`-`，删除 `、`、`.` 等标点（`定义、机制与基础研究` → `定义机制与基础研究`）。此前 `anchor(repo)`（仓库名 slug，不折叠空格）被同时当作标题锚点函数使用，译文只能选单词标题才能通过 `test_in_page_anchors_exist`；现在多词标题同样可用，`anchor(repo)` 本身与 `<a id="owner--repo">` 保持不变。
5. `test_zh_mirror_uses_canonical_review_data` 曾断言项目 `description` 出现在中文 README 中，但本仓库 README 表格只显示 `trigger`；改为 `trigger` 查 README、`description` 查 `docs/projects.md`。

## 事实与措辞修正

- `docs/readme-intro.md` 与 `locales/zh/docs/readme-intro.md` 原自称「中文精选目录 / Chinese-first」。默认语言已改为英语，zh 版改为「精选目录（英语默认，另含中文、西班牙语、印地语、法语版本）」，其余语言不再声称单一语言优先；两句能力宣传语逐句保留，未增删能力声明。
- 许可结论逐条沿用源文措辞（`README 声明 MIT`、`Apache-2.0（enterprise/ 除外）`、`待核验`），未升级为“已核验开源”。
- `locales/zh/CONTRIBUTING.md` 与三种译文的字段清单原缺 `trigger` 与 `papers.json`，已按 `validate()` 实况补齐。
- 论文标题保持官方英文原题，`publication_note` 只译说明文字。

## README 开头的分类标签导航

每份 README 在 intro 之后、「当前快照」之前新增 `## 分类导航`（en `Jump to a category`、es `Ir a una categoría`、hi `श्रेणी पर जाएँ`、fr `Aller à une catégorie`）：第一行按 `ui.json.categories` 顺序列出 7 个项目分类的页内链接，第二行以粗体 `**论文 / Papers / Artículos / शोध-पत्र / Publications**` 起头，列出 6 个论文分类链接，共 13 个 `### ` 小节一一对应（`test_tag_navigation_covers_every_category` 按 `len(categories)+len(paper_categories)` 断言，不写死数字）。

`heading_anchor()` 按 GitHub 渲染页实测校准：小写、空格转连字符，保留字母/数字/组合符/`_`/`-`，删除 `、`、`.` 等标点（npm 包 `github-slugger` 的字符集会保留 `、`，与 GitHub 页面实际生成的标题 id 不同，中途按它改过一次导致中文分类锚点跳不动，已回退）。仓库名锚点函数 `anchor(repo)` 与 `<a id="owner--repo">` 未改动，`docs/projects.md`、`docs/papers.md`、`docs/rankings.md`、`data/rankings.csv` 零 diff。

## 局限

译文由模型生成、未经母语者复核；`record/` 与 `research/` 保持撰写时原文（中文），不做机器翻译。`.local/` 下的抓取与台账文件仍留在本地（已 gitignore），不入仓。
