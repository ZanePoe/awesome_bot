# Paper catalogue

Titles and first-submission dates were verified against the original arXiv abstract pages (2026-11-05). Versions or renames of the same arXiv ID count as one paper. Conference status without independent verification is left as arXiv.


## [Foundations of Proactive Agents: Principles, Technical Layers, and Proactivity-Gym](https://arxiv.org/abs/2609.37267)

- Category: Definitions, mechanisms and foundational research; first submitted: 2026-09-29; arXiv; conference status not independently verified.
- Research question: Discusses the technical layers and user costs of proactive agents and introduces Proactivity-Gym.
- Reading boundary: A conceptual framework and evaluation environment, not a product-quality leaderboard.
- Resources: No code link verified in this round.

## [ContextAgent: Context-Aware Proactive LLM Agents with Open-World Sensory Perceptions](https://arxiv.org/abs/2505.14668)

- Category: Definitions, mechanisms and foundational research; first submitted: 2025-05-20; NeurIPS 2025 (noted on the paper page).
- Research question: Uses sensory context from wearable devices and historical user profiles to predict when to provide a service and invoke tools.
- Reading boundary: Sensing and service-prediction evaluations cannot be equated with full autonomous desktop control.
- Resources: [Code](https://github.com/openaiotlab/ContextAgent).

## [Proactive Agent: Shifting LLM Agents from Reactive Responses to Active Assistance](https://arxiv.org/abs/2410.12361)

- Category: Definitions, mechanisms and foundational research; first submitted: 2024-10-16; arXiv; conference status not independently verified.
- Research question: Predicts user tasks from desktop events and studies proactive assistance without explicit instructions.
- Reading boundary: A research implementation and benchmark, not a mature resident-assistant product.
- Resources: [Code](https://github.com/thunlp/ProactiveAgent).

## [Generative Agents: Interactive Simulacra of Human Behavior](https://arxiv.org/abs/2304.03442)

- Category: Definitions, mechanisms and foundational research; first submitted: 2023-04-07; arXiv; conference status not independently verified.
- Research question: Studies building simulated agents that live and interact autonomously through memory, reflection and planning.
- Reading boundary: Foundational simulated-world research, not a personal computer assistant.
- Resources: No code link verified in this round.

## [nanoMuse: An Open-Source Personal Agent for Every Device You Own](https://arxiv.org/abs/2610.08699)

- Category: Personal agent systems; first submitted: 2026-10-06; arXiv; conference status not independently verified.
- Research question: Presents the software architecture, memory design and continuous-interaction design of a cross-device personal agent.
- Reading boundary: A systems paper; the authors' priority claims are not treated as verified fact.
- Resources: [Code](https://github.com/nano-muse/nanoMuse).

## [MemoProAgent: Toward Memory-Driven Proactive Assistance](https://arxiv.org/abs/2610.22671)

- Category: Long-term memory and latent needs; first submitted: 2026-10-15; arXiv; conference status not independently verified.
- Research question: Studies retrieving intervention evidence from long-term personal memory so that memory participates in the decision of whether to speak up.
- Reading boundary: The latest version's title is MemoProAgent; the earlier name ProPerAgent is not listed separately.
- Resources: [Code](https://github.com/facebookresearch/Memo-Pro-Agent).

## [PASK: Toward Intent-Aware Proactive Agents with Long-Term Memory](https://arxiv.org/abs/2604.08000)

- Category: Long-term memory and latent needs; first submitted: 2026-04-09; arXiv; conference status not independently verified.
- Research question: Combines long-term memory, live context and latency constraints to detect latent needs and choose between assisting and staying silent.
- Reading boundary: Author-labelled technical report; research in progress.
- Resources: [Code](https://github.com/xzf-thu/Pask).

## [π-Bench: Evaluating Proactive Personal Assistant Agents in Long-Horizon Workflows](https://arxiv.org/abs/2605.14678)

- Category: Proactivity evaluation benchmarks; first submitted: 2026-05-14; arXiv; conference status not independently verified.
- Research question: Evaluates hidden-need recognition and proactive assistance across long multi-turn workflows.
- Reading boundary: Task completion rate and proactivity are different metrics.
- Resources: [Code](https://github.com/Simplified-Reasoning/Pi-Bench).

## [KnowU-Bench: Towards Interactive, Proactive, and Personalized Mobile Agent Evaluation](https://arxiv.org/abs/2604.08455)

- Category: Proactivity evaluation benchmarks; first submitted: 2026-04-09; arXiv; conference status not independently verified.
- Research question: Evaluates mobile agents on interactively eliciting preferences, intervening proactively, asking for consent, or staying silent.
- Reading boundary: Mobile GUI and personal-preference scenarios; desktop workflows need separate testing.
- Resources: [Code](https://github.com/ZJU-REAL/KnowU-Bench).

## [Proactive Agent Research Environment: Simulating Active Users to Evaluate Proactive Assistants](https://arxiv.org/abs/2604.00842)

- Category: Proactivity evaluation benchmarks; first submitted: 2026-04-01; arXiv; conference status not independently verified.
- Research question: Studies proactive assistants in a simulated environment with stateful apps and active users.
- Reading boundary: Simulated-user results cannot directly replace evaluation with real long-term users.
- Resources: [Code](https://github.com/deepakn97/pare).

## [ProactiveBench: Benchmarking Proactiveness in Multimodal Large Language Models](https://arxiv.org/abs/2603.19466)

- Category: Proactivity evaluation benchmarks; first submitted: 2026-03-19; ECCV 2026 (noted on the paper page).
- Research question: Evaluates whether multimodal models proactively gather extra information to complete visual tasks.
- Reading boundary: Different from the identically named benchmark used by ProactiveAgent; the paper page currently notes ECCV 2026.
- Resources: [Code](https://github.com/tdemin16/proactivebench).

## [PIRA-Bench: A Transition from Reactive GUI Agents to GUI-based Proactive Intent Recommendation Agents](https://arxiv.org/abs/2603.08013)

- Category: Proactivity evaluation benchmarks; first submitted: 2026-03-09; arXiv; conference status not independently verified.
- Research question: Recommends likely intents from continuous GUI screenshots and user context.
- Reading boundary: Intent recommendation and actually completing the recommended task must be evaluated separately.
- Resources: No code link verified in this round.

## [ProAgentBench: Evaluating LLM Agents for Proactive Assistance with Real-World Data](https://arxiv.org/abs/2602.04482)

- Category: Proactivity evaluation benchmarks; first submitted: 2026-02-04; arXiv; conference status not independently verified.
- Research question: Evaluates the timing and content of proactive assistance using real workflow logs.
- Reading boundary: Focused on judging proactive assistance; not a system-level reliability test.
- Resources: No code link verified in this round.

## [MyPCBench: A Benchmark for Personally Intelligent Computer-Use Agents](https://arxiv.org/abs/2606.16748)

- Category: Computer use and personalized execution; first submitted: 2026-06-15; arXiv; conference status not independently verified.
- Research question: Evaluates computer-use assistants in digital environments holding personal data and logged-in state.
- Reading boundary: A personalized-execution evaluation; it cannot replace intervention-timing evaluation.
- Resources: No code link verified in this round.

## [OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments](https://arxiv.org/abs/2404.07972)

- Category: Computer use and personalized execution; first submitted: 2024-04-11; arXiv; conference status not independently verified.
- Research question: Provides an open-ended task-execution benchmark in real computer environments.
- Reading boundary: Primarily measures execution capability; it does not show that agents discover tasks on their own.
- Resources: [Code](https://github.com/xlang-ai/OSWorld).

## [Sleeper Channels and Provenance Gates: Persistent Prompt Injection in Always-on Autonomous AI Agents](https://arxiv.org/abs/2605.13471)

- Category: Long-running operation and reliability research; first submitted: 2026-05-13; arXiv; conference status not independently verified.
- Research question: Analyzes indirect prompt-injection paths that persist across memory, skills, scheduling and the file system.
- Reading boundary: An architecture and threat study, not a general security rating across current products.
- Resources: No code link verified in this round.

## [Mind Your HEARTBEAT! Claw Background Execution Inherently Enables Silent Memory Pollution](https://arxiv.org/abs/2603.23064)

- Category: Long-running operation and reliability research; first submitted: 2026-03-24; arXiv; conference status not independently verified.
- Research question: Studies silent memory pollution caused by background heartbeat runs touching untrusted content.
- Reading boundary: The evaluation is version-bounded; pre-fix conclusions must not be applied to all current versions.
- Resources: No code link verified in this round.
