# 论文目录

依据 arXiv 原始摘要页核验标题和首次提交日期（2026-11-05）。同一 arXiv ID 的版本/更名只计一篇。没有独立核验的会议状态保留为 arXiv。


## [Foundations of Proactive Agents: Principles, Technical Layers, and Proactivity-Gym](https://arxiv.org/abs/2609.37267)

- 类别：定义、机制与基础研究；首次提交：2026-09-29；arXiv；未另行核验会议状态。
- 研究问题：讨论主动 Agent 的技术层次与用户成本，并提出 Proactivity-Gym。
- 阅读边界：概念框架与评测环境，不等于产品质量排行榜。
- 资源：尚未在本轮核验代码链接。

## [ContextAgent: Context-Aware Proactive LLM Agents with Open-World Sensory Perceptions](https://arxiv.org/abs/2505.14668)

- 类别：定义、机制与基础研究；首次提交：2025-05-20；NeurIPS 2025（论文页注明）。
- 研究问题：利用可穿戴设备的感知上下文与历史画像，预测何时提供服务及调用工具。
- 阅读边界：感知与服务预测评测不能直接等同于全桌面自主控制。
- 资源：[代码](https://github.com/openaiotlab/ContextAgent)。
